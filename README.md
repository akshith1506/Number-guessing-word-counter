# Number Guessing Game & Word Counter

## Project Description

A Python project that combines a number guessing game and a text-file word counter. The project demonstrates the use of Python loops, functions, the random module, file handling, dictionaries, and basic string manipulation.

## Features

### Number Guessing Game
- Generates a random number between 1 and 100
- Allows the user to guess the number
- Displays "Too High" or "Too Low"
- Tracks the number of attempts
- Calculates a score
- Displays the correct number when the game ends

### Word Counter
- Reads text from a file
- Converts text to lowercase
- Counts the total number of words
- Calculates the frequency of each word

### Menu
- Number Guessing Game
- Word Counter
- Exit
- Invalid choice validation

## Technologies Used

- Python
- Random Module
- File Handling
- Dictionaries
- Loops
- Functions
- String Manipulation

## Project Files

- `number_guessing_word_counter.py` – Main Python program
- `sample.txt` – Sample text file used for word-frequency analysis

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run `number_guessing_word_counter.py`.
5. Select an option from the menu.
